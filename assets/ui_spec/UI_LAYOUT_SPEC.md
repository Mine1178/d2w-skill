# D2W 默认 UI 布局规范（Wifibond 风格）

> 版本：v1.0.0（2026-10-12）｜ 适用范围：用 D2W 开发的所有 GUI 桌面软件
> 来源：`D:\Desktop\SD\11.Wifibond`（WiFiBond v1.2.8 实测界面）+ Address Tool 家族既有设计语言。
> **优先采用本风格；确不适合时按 §三 选择替代风格，但同一软件内必须全程统一，禁止混搭。**

---

## 一、设计原则（六条）

1. **一致性优先**：配色、字体、间距全部走统一常量（见 §四），禁止 4/6/8/10/12/16 混用、9/10/11/12/18/24 字号混乱。
2. **左导航 + 右内容**：多页面/设置较多的工具默认「左侧深色导航栏 + 右侧浅色内容区」框架（本技能默认布局）。
3. **卡片化布局**：每个功能区块是一个「白底卡片」——1px 边框 + 顶部 4px 强调色条，视觉层级清晰。
4. **响应式适配**：内容区宽度跟随视口，卡片列数 1~3 动态计算，表格列宽按权重自适应，永不横向溢出。
5. **信息密度适中**：表格行高 30px，正文 10pt、辅助 9pt，高 DPI 下不过密。
6. **可访问性**：颜色用于强调而非唯一信息载体（图标 + 文字并用）；对比度达标；最小字号 9pt。

## 二、默认布局：左导航 + 右内容（多页面工具）

```
┌───────────────────────────────────────────────┐
│ 左侧导航区 (宽 210px，深色底)                   │
│ ┌───────────────────────────────────────────┐ │
│ │ Logo 区 (高 110px)                         │ │
│ │   ◉ 产品名  /  一句功能定位               │ │
│ ├───────────────────────────────────────────┤ │
│ │ 导航菜单：🏠首页 📄功能页 ⚙️设置 ℹ关于      │ │
│ ├───────────────────────────────────────────┤ │
│ │ (弹性空白)                                 │ │
│ ├───────────────────────────────────────────┤ │
│ │ 状态栏 (高 42px) 版本号                     │ │
│ └───────────────────────────────────────────┘ │
└───────────────────────────────────────────────┘   ┌──────────────────────────────┐
                                                    │ 右侧内容区 (浅灰底)           │
                                                    │ Canvas 滚动容器 + 垂直滚动条 │
                                                    │ 页面头 + 卡片组              │
                                                    └──────────────────────────────┘
```

| 规范项 | 值 | 说明 |
|---|---|---|
| 左侧导航宽度 | 210 px | `pack_propagate(False)` 固定 |
| Logo 区高度 | 110 px | 固定，防被内容撑开挤压菜单 |
| 状态栏高度 | 42 px | 固定，避免版本号文字换行顶出屏幕 |
| 内容区滚动 | Canvas + 垂直 Scrollbar | 只纵向滚动，**永不出现横向滚动条** |
| 页面外边距 | padx=16, pady=12 | 统一 |
| 窗口初始尺寸 | min(1080, 屏宽×0.85) × min(700, 屏高×0.85) | 小屏不超出可视区 |
| 窗口最小尺寸 | 900 × 600 | `root.minsize` |
| 高 DPI | 进程级 DPI 感知（shcore/SetProcessDPIAware） | 100/125/150% 文字不模糊 |
| 切换页面 | 滚动位置归零 | 避免沿用旧滚动位置 |

**页面内部结构**：页面头（PageHeader：主标题 + 副标题 + 2px 强调分隔线）→ 卡片组（等宽 grid，`weight=1, uniform` 同组名，窄窗等比压缩）。

## 三、风格选择决策（什么时候换风格）

| 软件形态 | 推荐布局 | 说明 |
|---|---|---|
| **多页面 / 设置多 / 管理类工具**（默认） | **Wifibond 左导航 + 右内容** | 本技能默认风格，直接用 §二/§四/§五 |
| 单窗口小工具（翻译弹窗、划词浮窗、托盘小助手） | **居中单窗 + 紧凑表单** | 无导航栏；顶部标题 + 中部控件 + 底部按钮行；按钮右对齐 |
| 弹窗/浮窗类（划词翻译、通知） | **无边框圆角浮窗** | 跟随鼠标/锚点定位；内容紧凑；主按钮强调色 |
| Web/HTML 应用 | **顶部导航 + 内容区（或侧栏）** | 用 html skill 的响应式规范；同样卡片化 + 统一色板 |
| 复杂专业工具（表格密集） | **左导航 + 工具栏 + 主表格区** | 顶部工具栏放常用操作；表格权重自适应列宽 |

**决策规则**：默认用 Wifibond 风格；只有当产品形态明显不匹配（单窗/浮窗/Web）才换，换之前先向用户说明理由。**同一软件内全程统一**——换风格只允许发生在项目起点（PRD 阶段定死），开发中禁止混搭。

## 五、组件规范

| 组件 | 规范 |
|---|---|
| **页面头** | 主标题（F_H1 bold）+ 副标题（F_SECTION, 次级色）+ 2px 强调分隔线；标题 wraplength 随宽度自适应 |
| **卡片** | 白底 + 1px 边框（C_BORDER）+ 顶部 4px 强调条 + 可选描述 + 内容容器；描述 wraplength 自适应 |
| **面板** | 页面内轻量区块容器（白底 + 边框 + 顶条），同卡片结构无 hover |
| **表格** | 行高 30px；无边框；表头浅底 9pt bold；列宽按权重自适应（不横向溢出）；每表配独立垂直滚动条；选中行浅蓝底 |
| **按钮五级** | 扁平无边框（bd=0, cursor="hand2"）：primary 橙底白字（主动作）/ secondary 浅底深字（次动作）/ info 蓝底白字 / success 绿底白字 / danger 红底白字；内边距 padx=12 pady=4；按钮组水平排列间距 8px |
| **空状态** | 无数据时显示灰色引导文案（如「暂无规则——点击新增规则添加第一条」），不显示空白表格 |
| **弹窗/模态** | transient + lift + grab_set；resizable(False)；居中于主窗；内边距 padx=16；长文本 wraplength 自适应 |
| **关于页 / 赞助按钮** | 关于页底部放一个「☕ 赞助作者」按钮（secondary 浅底深字，与五级按钮同规格，不突兀）；点击弹模态窗：标题"请作者喝杯咖啡"，副标题"如果你喜欢这个工具，可以请作者喝杯咖啡，感谢赞助"，下方左右并列支付宝+微信收款码图片（等大、居中），窗口大小刚好包络两张码图（约 420×380，按码图实际尺寸微调），不可缩放；码图从项目 `assets/` 或打包资源读取（不硬编码绝对路径），源文件见 `D:\Desktop\SD\13.Rename\Money_code\{alipay,wechatpay}.jpg` |

## 六、响应式与可访问性

- 卡片列数动态：`cols = max(1, min(3, 容器宽 // 240))`；列数不变时不重建（防闪烁）
- 所有 wraplength 在 `<Configure>` 中按实际宽度刷新，适配任意缩放
- 对比度：主文字对白卡 ≈16:1；次级文字 ≈4.6:1（满足 AA）
- 状态同时用文字/图标表达（「🟢 运行中」「已连接/断开」），颜色不作唯一载体
- 交互控件统一 `cursor="hand2"`；最小字号 9pt；后台耗时操作必须走线程 + 安全回投 UI 线程

## 八、新增界面自检（派给 WorkBuddy 的 GUI 任务必带）

1. 容器/页面边距用统一常量（padx=16, pady=12）
2. 页面头用「主标题+副标题+分隔线」组件
3. 区块用卡片（白底+边框+顶条），强调色按语义（核心=橙、信息=蓝、成功=绿、危险=红）
4. 所有颜色/字号/间距引用常量，禁止硬编码魔法值
5. 表格用统一样式 + 独立滚动条 + 权重自适应列宽
6. 按钮按五级语义选底色，bd=0、cursor=hand2
7. 无数据时空状态文案明确
8. 弹窗 transient+grab_set+居中+不可缩放
9. 长文本全部 wraplength 自适应
10. 后台耗时操作走线程回投 UI 线程
11. 关于页含「☕ 赞助作者」按钮（secondary 风格），点击弹收款码窗（支付宝+微信并列，码图完整，窗口大小以码图完整显示为准）；码图走资源路径不硬编码
