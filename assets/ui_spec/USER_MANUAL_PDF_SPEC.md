# 产品使用手册 — PDF 样式规范（USER_MANUAL_PDF_SPEC.md）

> 一站式交付 §5.3 的样式依据。参照两份实测手册提炼：
> ①《通信工程勘察报告工具箱使用指南》（PDF，A4，蓝色封面线 + 圆点线目录 + 蓝底表头）
> ②《地址坐标转换工具使用指南》（docx→PDF，深蓝 1F3864 标题体系 + 中文序号 + 编号表格）
> 产物：`<cwd>/dist/<产品名>_使用手册.pdf`（同时保留 docx/md 源，便于修订）。

## 1. 总体设计（量化指标，生成时逐项落实）

| 项 | 规范 |
|---|---|
| 页面 | **A4 纵向**（210×297mm），页边距：上下 2.5cm、左右 3cm |
| 主色 | **深蓝 #1F3864**（标题/章节/表头） |
| 辅助色 | 灰 #595959（封面副信息、版本行）、黑 #000000（正文） |
| 强调线 | 封面装饰线/分隔线用 #1F3864 或 #4472C4 蓝 |
| 中文字体 | 微软雅黑（无则宋体）；西文 Arial |
| 字号层级 | 封面主标题 26pt 加粗 / 章节标题 16pt 加粗 / 节标题 14pt 加粗 / 正文 12pt / 表内 10.5pt |
| 行距 | 正文 1.5 倍；表格单倍 |

## 2. 封面版式（第 1 页）

自上而下居中排布：
1. 顶部留白 1/3 页高
2. 小标签行：「使用手册」/「用户手册」（12~14pt，灰 #595959，字间可加空格如"使 用 手 册"）
3. **主标题**：<产品名>（26pt 加粗，深蓝 #1F3864，居中）
4. 可选副标题：一句话定位（如"基于 XX 的 XX 系统"，14pt，灰）
5. 蓝色分隔线（宽度约页面 40%，#1F3864）
6. 信息块（12pt，灰，逐行）：
   - 文档版本：V<版本号>
   - 适用平台：Windows 10/11 等
   - 编制日期：<YYYY 年 MM 月>
   - 编制单位/联系方式（有则写，无则省略）

## 3. 目录版式（第 2 页起）

- 标题「目 录」居中（16pt 加粗，深蓝 #1F3864），下方加蓝色短横线
- 条目：`章节标题 .... 页码`——**圆点线连接，页码右对齐**（勘察报告手册样式）
- 层级缩进：章 0 缩进 / 节 1 级 / 小节 2 级（缩进单位约 1cm）
- 目录必须真实对应正文页码（生成后逐条核对）

## 4. 正文版式

| 元素 | 规范 |
|---|---|
| 章标题 | 16pt 加粗深蓝 #1F3864，段前段后留白，如「第一章 软件概述」或「一、软件简介」（两套编号风格任选其一，全程统一） |
| 节标题 | 14pt 加粗深蓝，如「1.1」「（一）」 |
| 小节标题 | 12pt 加粗黑，如「1.1.1」「1）」 |
| 正文 | 12pt 黑，1.5 倍行距，两端对齐 |
| 操作步骤 | 数字编号「1. 2. 3.」，与界面按钮文字用「」引号标注 |
| 表格 | **表头蓝底 #1F3864 白字**（或浅蓝 #D9E2F3 底深蓝字），正文行白底黑字、网格线；表上方写「表 N <表题>」，正文引用「如表 N 所示」 |
| 图片/截图 | 居中，下方图注「图 N <图题>」（10.5pt 灰） |
| 页眉 | 左「<产品名> 使用手册」，右「V<版本号>」（9pt 灰） |
| 页脚 | 居中页码（9pt 灰），封面页不显示页码 |

## 5. 章节结构（内容模板，与 USER_MANUAL.template.md 对应）

```
第一章 软件简介        （定位、核心功能表、运行环境）
第二章 安装与启动      （安装/免安装、界面总览）
第三章 快速上手        （5 步内跑通主流程）
第四章 功能详解        （逐功能：操作步骤 + 界面位置 + 示例 输入→输出）
第五章 数据与格式      （Excel/文件规范、字段表、模板下载）
第六章 设置说明        （配置项、配置文件位置）
第七章 常见问题 FAQ    （表：问题|原因|解决）
第八章 快捷键与技巧    （表：快捷键|功能）
第九章 版本更新与支持  （版本记录、联系方式、更新渠道）
（附录可选：错误码表、隐私说明）
```

## 6. 生成技术路径（二选一，推荐 A）

**路径 A：docx → PDF（推荐，样式可控、本机必有 Word）**
1. 用 python-docx 按本规范排版生成 `USER_MANUAL.docx`（标题/表格/字体/颜色全部量化设置）
2. 用 Word COM 转 PDF：
```python
import win32com.client
w = win32com.client.Dispatch("Word.Application"); w.Visible = False
d = w.Documents.Open(r"<abs>\USER_MANUAL.docx"); d.SaveAs(r"<abs>\USER_MANUAL.pdf", FileFormat=17); d.Close(); w.Quit()
```
（FileFormat=17 = wdFormatPDF；docx 与 pdf 同目录同名）

**路径 B：HTML → PDF（备选，样式最自由）**
- 写 `USER_MANUAL.html`（内嵌 CSS，按本规范），用 Edge/Chrome headless 打印为 PDF：
```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --print-to-pdf="<abs>\USER_MANUAL.pdf" --no-pdf-header-footer "<abs>\USER_MANUAL.html"
```

## 8. 验收清单（审核方在成品 PDF 上逐条过）

- [ ] 封面：主标题/副标题/版本/日期完整，无错别字、无乱码
- [ ] 目录：章节与正文一致，页码真实对应，圆点线对齐
- [ ] 正文：中文字体完整（无方框/缺字），标题层级清晰
- [ ] 表格：表头蓝底、不跨页截断、编号与引用对应
- [ ] 截图/图注存在且清晰（GUI 软件手册必须有真实截图）
- [ ] 页眉页脚/页码正确，封面无页码
- [ ] 与实际软件一致：功能名称、按钮文字、路径与成品完全相符（不符 = P1）
- [ ] PDF 可直接打开、页数合理（一般 8~20 页）
